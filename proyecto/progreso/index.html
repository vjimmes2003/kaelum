Cómo se conectan

Cada objetivo se apoya en el core: movimiento, gunplay, lectura del entorno y decisiones rápidas. La historia no compite por tiempo con el jugador: lo refuerza.

Cuando hay narrativa

  • Contexto breve antes de una parte importante
  • Consecuencia visible tras una decisión
  • Información útil que cambia cómo juegas

Cuando no la hay

  • Exploración libre
  • Combate y dominio del core
  • Ritmo y flow del nivel
// CIERRE

Resumen

Progreso simple, defendible y actualizable: objetivos claros, ritmo controlado y un enfoque coherente con el proyecto.
